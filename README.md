# CodeRabbit

Configuration and notes repository for **[CodeRabbit](https://coderabbit.ai/)** AI code review integration.

## Purpose

Use this repo to store:

- CodeRabbit config (`.coderabbit.yaml` when added)
- Review guidelines and team conventions
- Experiment branches for PR review workflows

## Setup

1. Install the CodeRabbit GitHub App on target repositories.
2. Add configuration files at the repo root per [CodeRabbit docs](https://docs.coderabbit.ai/).
3. Open a pull request to trigger automated review.
